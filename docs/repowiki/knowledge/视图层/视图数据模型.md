## Provenance（每节的 sources 字段）

`Provenance`（[view.go:82-86](file://internal/view/view.go#L82-L86)）作为嵌入字段出现在 `Project`、`Progress`、`Runs`、`Records`、`Knowledge` 五节中：

```go
type Provenance struct {
    Sources []string `json:"sources"`
}
```

**关键约定**（[collect.go:96-123](file://internal/view/collect.go#L96-L123)）：

- **路径全部用项目相对 slash 形式**（Windows 也用 `/`），不混用 `\`。
- **`/` 后缀 = 目录**；无 `/` = 文件。例如 `.devsys/runs/`（runs 目录）vs `.devsys/runs/run-1.jsonl`（具体文件）。
- 来源路径为空的字符串一律丢弃（`noteRel/noteRelDir` 都有 `if rel == ""` 早退）。
- 每节 `Sources` 都过 `sortedUnique`，顶层 `Sources` 又过一次——保证「读端记啥就出啥」。

调用方可以通过 `m.Project.Sources`、`m.Knowledge.Sources` 等逐节追溯每一段事实读了哪些文件；顶层 `m.Sources` 是全量并集 + `git` 基线（基线不在 `.devsys/` 下，不进各节 `Provenance.Sources`，但加入顶层）。

## `Options`（Build 的注入参数）

```go
type Options struct {
    Now  func() time.Time  // 可选；零值时 Build 用 time.Now；作为 Build 的时钟同时喂 storage.Open / reconcile.Doctor / next.Evaluate，但绝不写进 JSON
    Limit int              // 可选；零值或负值时用 DefaultLimit；只作用于列表节

```

- `Now` 注入的目的是让测试控制时钟（`storage.Open` / `reconcile.Doctor` / `next.Evaluate` 共用同一份）；模型不带 `Now`——这是确定性保证。
- `Limit` 影响的是 `Runs/Records/Knowledge.Pages` 等「列表节」；`Progress.Items` 与 `Project.Milestones` **不**截断（[view.go:27-30](file://internal/view/view.go#L27-L30) 注释：`work items and milestones are never capped — they are the board itself`）。

## JSON 编码约定汇总

- **`omitempty` 的统一规则**：所有可选字段（`omitempty` 标签）都是「空时省略」，让 `Problems/Risks/Blockers/...` 这种空集合不出现在 JSON 里。
- **slice 预填为空**（`newModel`）：保证「没找到」是 `[]` 不是 `null`——这是确定性 + JSON 信封稳定的基础。
- **目录以 `/` 结尾**：路径字符串最后是 `/` 表示目录，最后是文件名（或不带 `/`）表示文件；这是 `Sources` 字段的语义约定。
- **时间字段**：`Item.CreatedAt/UpdatedAt` 是 `time.Time`（必有）；`Project.CreatedAt/UpdatedAt`、`RecordRef.CreatedAt`、`RunEntry.FinishedAt` 是 `*time.Time`（零值省略）。
- **指针字段**：`Baseline.Dirty`（`*bool`）、`Item.LeaseUntil`（`*time.Time`）、`Item.NextAttemptAt`（`*time.Time`）、`RunEntry.FinishedAt`（`*time.Time`）、`RunEntry.Advanced`（`*bool`）、`RecordRef.CreatedAt`（`*time.Time`）。
- **map 字段**：`Progress.Counts` 是 `map[string]int`，**有 `omitempty`** 不会生效（Go 的 json 包对 map 不判 nil → 总是输出）——但 `newModel` 预填 `map[string]int{}` 而不是 `nil`，保证输出 `{}` 而非 `null`。
- **枚举值**：所有状态字段是字符串常量，渲染层按字符串分支，不要把字符串哈希为整数。
