# 读快照与守卫更新 · 可靠文本存储

M4 把「读 + 守卫写」模式显式化为可重用的存储层 API：`ReadDecision / ReadFinding / ReadArtifact` 一并返回解码后的对象与原 YAML 字节；更新方法（`UpdateDecision / UpdateFinding / AppendArtifactVersion`）的 `expected` 参数要求**来自读取方法返回的同一批字节**，通过 `bytes.Equal` 在写锁内重读时再校验。

## `readSnapshot[T]` 泛型

`internal/record/update.go:32-58`：

```go
func readSnapshot[T any](s *Store, ctx context.Context, kind Kind, id string) (*T, []byte, error) {
    if !kind.ValidID(id) {
        return nil, nil, fmt.Errorf("%w: %q", ErrBadID, id)
    }
    st, err := s.store()
    if err != nil {
        return nil, nil, err
    }
    var (out = new(T); raw []byte)
    err = st.Read(ctx, func(r *storage.Reader) error {
        data, exists, err := r.Read(kind.dir() + "/" + id + ".yaml")
        if err != nil { return err }
        if !exists { return ErrNotFound }
        if err := domain.DecodeYAML(data, out); err != nil { return err }
        raw = data
        return nil
    })
    if err != nil { return nil, nil, err }
    return out, raw, nil
}
```

要点：

- 共享锁下读（`st.Read`），不创建锁文件、不触发事务恢复。
- `raw` 与解码对象**来自同一份字节**，调用方拿到的是真正可用于守卫的 `expected`。
- `id` 形状校验在文件 IO 之前——避免 `../` 或非法字符穿透到路径解析。

func versionHash(raw []byte) string {
    sum := sha256.Sum256(raw)
    return hex.EncodeToString(sum[:])
}

## `UpdateDecision / UpdateFinding`

`internal/record/update.go:62-68`：

```go
func (s *Store) UpdateDecision(ctx context.Context, d *domain.Decision, expected []byte) error {
    return s.update(ctx, KindDecision, d, d.ID, expected)
}
func (s *Store) UpdateFinding(ctx context.Context, f *domain.Finding, expected []byte) error {
    return s.update(ctx, KindFinding, f, f.ID, expected)
}
```

`s.update` 内部走 `st.Write` + `tx.ReadForExpect` + `ExpectHash(HashBytes(expected))`；并发写 → `storage.ErrConflict`。

调用契约定型：

1. `DecisionGet(ctx, id)` → `(view, version)`。
2. 客户端修改 `view.Decision`（不能改 `ID`）。
3. `DecisionUpdate(ctx, view.Decision, raw)`（`raw` 来自 `view` 的内部持有）。
4. CLI 的 `--expect <version>` 与 MCP 工具的 `expect` 字段在 `app.DecisionUpdate` 内被翻译为 `expected` 字节。

## `AppendArtifactVersion` 与线性版本链

`internal/record/update.go:75-100+`：

```go
var ErrSuperseded = errors.New("record: artifact already has a newer version")

func (s *Store) AppendArtifactVersion(
    ctx context.Context, currentID string, expected []byte,
    mutate func(*domain.Artifact),
) (string, error)
```

线性链契约：

- 当前版本 `currentID` 在写事务内被 `tx.ReadForExpect` 重读；`expected` 不匹配 → `storage.ErrConflict`。
- `mutate(*domain.Artifact)` 修改拷贝（**不**改原文件）。
- 构造新 ID 时调用 `hasSuccessor(st, currentID)`：若 `currentID` 已有任何子版本 → `ErrSuperseded`。
- 写入新文件、`previous_id` 指回 `currentID`；原文件**永不**被改写。
- 返回新版本的 ID。

`ErrSuperseded` 的语义：**并发追加会失败而不是分叉**。解决路径是「re-read head + append from it」，应用层在 `app.ArtifactUpdate` 内捕获并翻译为 `app.Preconditionf("artifact %s already has a newer version; re-read and retry", currentID)`。
