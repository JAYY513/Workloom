# 可靠文本存储 · 编码规范

> 仅记录在 ≥2 处源码中验证过的惯例。

## 1. Sentinel 错误一律用 `%w` 包装

包内所有自定义 sentinel（`ErrConflict`、`ErrLockTimeout`、`ErrRecoveryFailed`、`ErrIncompleteTail`、`ErrUnsafePath`、`ErrSchemaVersion`、`ErrNotInitialized`）仅通过 `fmt.Errorf("%w: <context>", ErrXxx, ...)` 形式返回，便于上游 `errors.Is` 判别。

**验证依据**：
- [internal/storage/store.go:64,68,92,96,99,103,165](file://internal/storage/store.go#L64-L165)
- [internal/storage/lock.go:52,54](file://internal/storage/lock.go#L52-L54)
- [internal/storage/jsonl.go:69,95](file://internal/storage/jsonl.go#L69-L95)
- [internal/storage/recover.go:226](file://internal/storage/recover.go#L226)
- [internal/storage/serialize.go:86,89,92](file://internal/storage/serialize.go#L86-L92)
- [internal/storage/txn.go:233,237,256,264](file://internal/storage/txn.go#L233-L264)

非 sentinel 错误使用 `"<verb> %s: %w"`（`atomic.go:38,42,46,50`；`store.go:66,122`），保持上下文但不可识别。

## 2. 时间戳统一为 UTC + `time.RFC3339Nano`

所有写入磁盘或出现在错误消息中的时间戳统一 `s.opts.Now().UTC().Format(time.RFC3339Nano)`，便于跨机器排序与解析。

**验证依据**：
- [internal/storage/lock.go:82](file://internal/storage/lock.go#L82) — holder 描述的 `since` 字段
- [internal/storage/txn.go:279](file://internal/storage/txn.go#L279) — journal `created_at`
- [internal/storage/txn.go:307](file://internal/storage/txn.go#L307) — commit marker `committed_at`

`Options.Now`（`store.go:38`）默认 `time.Now`；测试可注入可控时钟。

## 3. `Options` 零值即合法，`Open` 内补默认

`Options{LockTimeout: 0, Now: nil}` 都视为合法：`Open` 中 `if opts.LockTimeout <= 0 { opts.LockTimeout = DefaultLockTimeout }`（`store.go:54-56`），`if opts.Now == nil { opts.Now = time.Now }`（`store.go:57-59`）。`DefaultLockTimeout = 5 * time.Second`（`store.go:31`）。

**验证依据**：
- [internal/storage/store.go:29-39,53-60](file://internal/storage/store.go#L29-L60)
- [internal/storage/store_test.go:17-26](file://internal/storage/store_test.go#L17-L26) — `TestOpenRequiresInitializedProject` 直接传 `Options{}`

测试在需要延长等待时间时显式传入 `Options{LockTimeout: 30 * time.Second}`（`helper_test.go:77`），是包内确认的合法覆盖方式。

## 4. 受管路径一律为 slash 格式的相对路径

`store.go:90-106` `resolve`：slash 形式（如 `workitems/x.yaml`）→ `filepath.FromSlash`；拒绝绝对路径、含 `\` / `:`、`.`、`..`、`local/lock`、`local/txn` 及其前缀。`payloadRel`（`txn.go:230-240`）进一步强制 payload 引用形如 `payload/NNN.bin` 且不含 `..`。

调用方必须直接传 `rel` 给 `Tx.Put` / `Tx.AppendJSONL` / `Reader.Read` / `Reader.Expect`，不要自行 `filepath.Join` 后传入；`store_test.go:60-71` `TestUnsafePathsAreRejectedBeforeAnyWrite` 验证逃逸尝试在写入前就被拒绝。
