# 可靠文本存储 · 编码规范

## 1. `ctx context.Context` 作为公开方法的第一个参数

所有领域 `Store` 的公开方法（`Create` / `Get` / `List` / `Update` / `ReadSnapshot` / `Append` / `Read` / `Comments` 等）都把 `ctx context.Context` 放在签名首位，与底层 `storage.Store.Read/Write`（[internal/storage/store.go:143,172](file://internal/storage/store.go#L143-L172)）保持一致；不持有上下文的私有辅助方法不强制（如 `nextNumber`、`listIDs`、`nextEventID`）。

## 2. 包级 sentinel 错误集中声明在 `var ( ... )`

每个领域包用 `var ( ... )` 块集中暴露 sentinel；调用方用 `errors.Is` 而非字符串匹配：

- `workitem`：`ErrNotInitialized`、`ErrNotFound`、`ErrConflict`、`ErrBadPrefix`（[internal/workitem/workitem.go:27-32](file://internal/workitem/workitem.go#L27-L32)）
- `events`：`ErrNotInitialized`、`ErrIncompleteTail`、`ErrReplyNotFound`、`ErrReplyNotOneLevel`、`ErrBadTime`（[internal/events/events.go:25-31](file://internal/events/events.go#L25-L31)）
- `run`：`ErrNotFound`、`ErrBadID`（[internal/run/run.go:26-29](file://internal/run/run.go#L26-L29)）
- `record`：`ErrNotFound`、`ErrBadID`、`ErrBadKind`、`ErrConflict = storage.ErrConflict`（[internal/record/record.go:34-40](file://internal/record/record.go#L34-L40)）

跨包复用 storage sentinel 的写法（`ErrConflict = storage.ErrConflict`、`ErrNotInitialized = storage.ErrNotInitialized`）让上层用 `errors.Is` 一处识别根状态——但**不**做"包装改名"，类型与原始一致。

## 3. ID 必须先验证格式，再做路径拼接

每个 ID 入口都先用正则（`regexp.MustCompile`）锚定模式，再做磁盘 / 事务操作；非法 ID 直接返回 `ErrBadID` / `ErrBadPrefix`，**永不**让恶意 ID 拼到 `dirRel+"/"+id+".yaml"`：

- [internal/workitem/workitem.go:43,46](file://internal/workitem/workitem.go#L43-L46)（`^[A-Z][A-Z0-9_]*-[0-9]+$`，`ValidID(id)`）；[workitem.go:57](file://internal/workitem/workitem.go#L57)（前缀单独校验 `^[A-Z][A-Z0-9_]*$`）
- [internal/run/run.go:31,45](file://internal/run/run.go#L31-L45)（`^run-[0-9]{8}-[0-9]+$`）；[run.go:68](file://internal/run/run.go#L68)（`Create` 事务内 `ValidID(id)` 二次校验）
- [internal/record/record.go:42-46,60](file://internal/record/record.go#L42-L60)（按 Kind 映射三个正则；`Kind.ValidID`）；[record.go:190-192](file://internal/record/record.go#L190-L192)（`get` 入口）

`workitem.Create` 还做 `strings.ToUpper(prefix)` 归一化，保证大写前缀统一（[internal/workitem/workitem.go:56](file://internal/workitem/workitem.go#L56)）。

## 4. 目录派生用 `dirRel` 常量 + 正斜杠，不混用 `filepath.Join`

落盘路径由包级 `const dirRel = "<dir>"` 派生，事务里只用 `dirRel + "/" + id + ".yaml"`，跨平台一致性由 storage 的 `resolve` 负责（参见 [架构设计](架构设计.md)）：

- [internal/events/events.go:22,46](file://internal/events/events.go#L22-L46)（`shardRel` 用 `fmt.Sprintf("%s/%04d-%02d.jsonl", dirRel, ...)`）
- [internal/run/run.go:23,80](file://internal/run/run.go#L23-L80)
- [internal/record/record.go:32,142](file://internal/record/record.go#L32-L142)（`(k Kind) dir() string` → `kind.dir()+"/"+id+".yaml"`）

`listIDs` 在枚举本地文件系统时**必须**用 `filepath.Join(st.DevsysDir(), filepath.FromSlash(dirRel))` 把存储路径与 OS 分隔符对接（[internal/run/run.go:207](file://internal/run/run.go#L207)、[internal/record/record.go:90](file://internal/record/record.go#L90)）。

## 5. CAS 分配 + 乐观并发统一结构

`workitem.Create`（[internal/workitem/workitem.go:55-88](file://internal/workitem/workitem.go#L55-L88)）、`run.Create`（[internal/run/run.go:51-92](file://internal/run/run.go#L51-L92)）、`record.create`（[internal/record/record.go:124-153](file://internal/record/record.go#L124-L153)）、`record.NewArtifactVersion`（[internal/record/record.go:280-325](file://internal/record/record.go#L280-L325)）共享同一形态：

```text
const maxAttempts = 5
for range maxAttempts {
    err = st.Write(ctx, func(tx *storage.Tx) error {
        next := nextNumber(...)             // 写锁内重扫
        id   := fmt.Sprintf("%s-%d", kind, next)
        ...                                  // 填充 v.ID、SchemaVersion、Version
        return tx.PutYAML(...+".yaml", v, storage.ExpectAbsent())
    })
    if err == nil                          { return id, nil }
    if errors.Is(err, storage.ErrConflict) { continue }
    return "", err
}
return "", fmt.Errorf("...gave up after %d conflicts", maxAttempts)
```

要点：

- `maxAttempts` 是包内 `const`，写死 5；
- 冲突用 `errors.Is(err, storage.ErrConflict)` 判定，**不**用 `==`；
- 失败后由调用方决定是否重试 / 报错。

## 6. `ReadSnapshot` + `Update(expected []byte)` 构成乐观并发对

读取路径必须返回**原始字节**而不是仅返回结构体，调用方在写回时把它直接喂给 `storage.ExpectHash(storage.HashBytes(expected))`。一旦字节不匹配，`storage` 直接报 `ErrConflict`，绝不静默覆盖（方案 §15.2）。

- [internal/workitem/workitem.go:166-195](file://internal/workitem/workitem.go#L166-L195)（`ReadSnapshot`）；[workitem.go:156-164](file://internal/workitem/workitem.go#L156-L164)（`Update` 用 `ExpectHash(HashBytes(expected))`）
- [internal/run/run.go:123-154](file://internal/run/run.go#L123-L154)（`ReadSnapshot`）；[run.go:194-202](file://internal/run/run.go#L194-L202)（`Update` 同形态）
- `storage.ExpectHash` / `storage.HashBytes` 定义：[internal/storage/txn.go:37,40](file://internal/storage/txn.go#L37-L40)

测试固定这一契约：`run_test.go:140-143` 用旧的 `snapA` 让第二次 `Update` 触发 `storage.ErrConflict`（[internal/run/run_test.go:140-143](file://internal/run/run_test.go#L140-L143)）。

## 8. 空目录宽容：`listIDs` 把 `os.ErrNotExist` 当零结果

`os.ReadDir` 拿到 `errors.Is(err, os.ErrNotExist)` 直接返回 `nil, nil`，不传播错误——未初始化的子目录视为合法空集：

## 9. 列表排序不依赖文件系统枚举 / mtime

`List` 必须返回**按 ID 派生键**排序的稳定序列，单线程与多线程遍历结果一致：

- `workitem.listIDs` 按 `(prefix, numeric suffix)` 二元组升序（[internal/workitem/workitem.go:216-258](file://internal/workitem/workitem.go#L216-L258)）
- `run.listIDs` 按 `(date, numeric suffix)` 二元组升序，用 `id[4:12]` 切日期（[internal/run/run.go:204-246](file://internal/run/run.go#L204-L246)）
- `record.listIDs` 按数字后缀升序（[internal/record/record.go:87-119](file://internal/record/record.go#L87-L119)）
- `events.listShards` 按月份升序（[internal/events/events.go:183-206](file://internal/events/events.go#L183-L206)）

`search.Search` 同样在 worker 汇总后做 `sort.Strings(files)`（[internal/search/search.go:68](file://internal/search/search.go#L68)），保证结果排序确定。

## 10. `search` 不持锁、排除固定目录

`search.Search`（[internal/search/search.go:44-127](file://internal/search/search.go#L44-L127)）的硬约束：

- `excluded = map[string]bool{".cache": true, "local": true}`（[internal/search/search.go:21](file://internal/search/search.go#L21)）；命中即 `fs.SkipDir`，**不**递归。
- **不**开 `storage.Store`，**不**取项目锁；纯 `filepath.WalkDir` + 多 worker。
- 每 worker 写自己槽位 `results[i]`，最终按 `files` 顺序扁平化，保证与单线程遍历结果一致。

## 11. 错误包装一律 `fmt.Errorf("%w: ...", sentinel, ...)`

跨包错误都用 `%w` 包装，便于上层 `errors.Is` 判定；格式串总是 `"<sentinel message>: <细节>"`，避免把 sentinel 字面量写到错误文本里再单独匹配：
