# 可靠文本存储 · 领域记录与事件

本卡描述 M1 在 storage 基元之上暴露给上层的四类领域存储模块及其公开契约。所有变更都经过 `internal/storage` 的独占事务协议；模块本身**不**持锁、不直接 `fsync`、不写 `.devsys/local/`。

## 公共形态

四个模块都遵循同一形态：

- `New(root string) *Store` 绑定项目根（必须含 `.devsys/`，否则 `storage.ErrNotInitialized`）。
- 私有方法 `(s *Store) store() (*storage.Store, error)` 复用 `storage.Open`（[internal/workitem/workitem.go:48](file://internal/workitem/workitem.go#L48)、[internal/events/events.go:42](file://internal/events/events.go#L42)、[internal/run/run.go:42](file://internal/run/run.go#L42)、[internal/record/record.go:57](file://internal/record/record.go#L57)）。
- 暴露 `ctx context.Context` 作为第一个参数（编码规范约定）。
- 包级 sentinel `ErrNotInitialized = storage.ErrNotInitialized`（[internal/workitem/workitem.go:28](file://internal/workitem/workitem.go#L28)、[internal/events/events.go:26](file://internal/events/events.go#L26)）让调用方用 `errors.Is` 跨越包边界判定根状态。
- 序列化通过 `domain.EncodeYAML` / `domain.DecodeYAML`，自动注入 `schema_version: 1` 与 `null`/`[]` 区分（[internal/domain/serialize.go:16-71](file://internal/domain/serialize.go#L16-L71)）。

  - 因此线程树深度恒为 2。
- **Filter 零字段匹配**：未设的时间与 `Subject` 边界都视为不限；`Subject` 必须 type+id 都匹配；`Type` 是精确匹配（[internal/events/events.go:96-126](file://internal/events/events.go#L96-L126)）。

## Record — `internal/record/`

`record` 是三种记录家族的统一入口：`KindDecision`、`KindFinding`、`KindArtifact`（[internal/record/record.go:26-30](file://internal/record/record.go#L26-L30)）；目录 = `string(Kind) + "s"`（[internal/record/record.go:32](file://internal/record/record.go#L32)）。

| Kind | 目录 | ID 模式 |
|---|---|---|
| `decision` | `.devsys/decisions/` | `^decision-[0-9]+$` |
| `finding` | `.devsys/findings/` | `^finding-[0-9]+$` |
| `artifact` | `.devsys/artifacts/` | `^artifact-[0-9]+$` |

正则映射见 [internal/record/record.go:42-46](file://internal/record/record.go#L42-L46)。

| 公开 API | 说明 |
|---|---|
| `New(root)` | 绑定根 |
| `CreateDecision(ctx, *Decision) (id, err)` | 见下 |
| `CreateFinding(ctx, *Finding) (id, err)` | 同上 |
| `CreateArtifact(ctx, *Artifact) (id, err)` | 同上；初始 `Version = 1`、`PreviousID = nil` |
| `GetDecision` / `GetFinding` / `GetArtifact` | 解码单条 |
| `ListDecisions` / `ListFindings` | 按 ID 升序 |
| `NewArtifactVersion(ctx, currentID, next) (newID, err)` | 不可变版本追加 |
| `ArtifactHistory(ctx, id) ([]*Artifact, error)` | 沿 `previous_id` 反向遍历，新→旧 |
| `Kind.ValidID(id) bool` | 各 Kind 的格式校验 |

不变量：

- **统一 CAS 入口**：`create(ctx, kind, v, setID func(int))` 收口三种记录的 CAS 分配；`setID` 闭包负责写 `v.ID` / `v.SchemaVersion`（[internal/record/record.go:124-153](file://internal/record/record.go#L124-L153)）；上限 5 次冲突。
- **Artifact 版本链不可变**：`NewArtifactVersion`（[internal/record/record.go:280-325](file://internal/record/record.go#L280-L325)）写锁内：
  1. `tx.ReadForExpect(artifacts/<currentID>.yaml)` 取当前字节 → `DecodeYAML` 到 `cur`；
  2. `*next = *cur` 浅拷贝全部字段；
  3. 重置 `next.ID = newID`、`next.SchemaVersion = domain.SchemaVersion`、`next.Version = cur.Version+1`、`next.PreviousID = &currentID`；
  4. `tx.PutYAML(artifacts/<newID>.yaml, next, ExpectAbsent())` 写**新文件**。
  现有版本文件**永不**被改写。
- **`ReadForExpect` 来源**：`storage.Tx.ReadForExpect` 在写锁内安全重读（[internal/storage/txn.go:167-180](file://internal/storage/txn.go#L167-L180)）；调用方无需自己再开 `st.Read`——那会与 `st.Write` 的独占锁冲突。
- **历史回放**：`ArtifactHistory`（[internal/record/record.go:329-351](file://internal/record/record.go#L329-L351)）从 `id` 沿 `PreviousID` 链反查；`seen[cursor]` 检测环 → `ErrBadID`；`PreviousID` 格式非法 → `ErrBadID`。
- **包级错误**：`ErrNotFound`、`ErrBadID`、`ErrBadKind`、`ErrConflict = storage.ErrConflict`（[internal/record/record.go:34-40](file://internal/record/record.go#L34-L40)）。
- **空目录容忍**：`listIDs` 用 `os.ReadDir`，目录不存在时返回 `nil`（[internal/record/record.go:91-93](file://internal/record/record.go#L91-L93)）；与 run 的同名行为一致（[internal/run/run.go:208-210](file://internal/run/run.go#L208-L210)）。

## 跨模块契约小结

| 契约 | 出处 | 含义 |
|---|---|---|
| `ctx context.Context` 首个参数 | 所有四个模块 | 与 storage 协议保持一致；调用方负责 cancel |
| `ErrNotInitialized = storage.ErrNotInitialized` | workitem、events | 让上层用 `errors.Is` 一处识别未初始化根 |
| 写前 `SchemaVersion == 0` → `domain.SchemaVersion` | workitem、events、run、record | 保证落地 YAML 永远带 `schema_version: 1` |
| CAS 上限 5 次 | workitem、run、record.create、record.NewArtifactVersion | 极端竞争放弃而非死循环；调用方需自行决定重试策略 |
| 列表排序按 `(kind, numeric)` 稳定 | workitem、run、record | 不依赖文件系统枚举顺序 |
| JSONL 断尾归 storage.ErrIncompleteTail | events | 事件层不做额外断尾判定，避免双重协议 |
