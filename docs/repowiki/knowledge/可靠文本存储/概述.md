# 可靠文本存储 · 概述

本模块覆盖 `.devsys/` 项目内**领域数据的落盘层**：任务（WorkItem）、事件流、Run 记录、决策/发现/工件记录，以及基于文本扫描的关键字检索。它建立在 [存储基元](存储错误语义.md) 的事务与锁之上，向上提供 Go API，检索另有 CLI 入口；不提供业务状态机。

## 模块定位

- **做什么**：把领域记录写成稳定键序的 YAML/JSONL 文本文件；分配全局唯一 ID；提供乐观并发更新与不可变版本链。
- **不做什么**：不理解状态机（M2）、不做门禁（M3）、不提供 CLI 领域命令（M4，`search` 除外）。

M2 起在可靠文本存储之上又承接了**调度**与**对账/修复**两块职责：状态机九态图与保守转换（`internal/domain/state.go`）、租约文件 `.devsys/scheduling/<id>.yaml` 下的领取/心跳/释放/重试（`internal/workitem/claim.go`），以及只读检查 / 恢复 / 确认式修复（`internal/storage/inspect.go` + `internal/reconcile/`）。这三者仍然全部落在 storage 的事务与锁之上，自身不引入新的锁类型。

## 职责边界

| 子层 | 目录 | 职责 |
|---|---|---|
| WorkItem | `internal/workitem/` | 一任务一文件，`<前缀>-<序号>` ID，CAS 分配；M2 状态机转换、租约领取/释放/重试 |
| 事件流 | `internal/events/` | JSONL 按月分片追加，评论一级回复；提供 `AppendTx` 走同一事务 |
| Run | `internal/run/` | `run-<YYYYMMDD>-<N>`，携带 §11.3 上下文快照 |
| 记录 | `internal/record/` | decision/finding/artifact 一记录一文件；Artifact 版本链 |
| 检索 | `internal/search/` | 无索引文本扫描，排除 `local/`、`.cache/` |
| 只读检查 | `internal/storage/inspect.go` | 共享项目锁下的 `Inspect` / `InspectUnlocked`，**不**创建锁文件、**不**触发恢复 |
| 对账/修复 | `internal/reconcile/` | Doctor（只读）/ Recover（释放过期/孤儿租约）/ RepairDryRun + RepairApply（确认式） |

物理布局见 [架构设计](架构设计.md)；错误语义见 [存储错误语义](存储错误语义.md)。
