# 可靠文本存储 · 概述

本模块覆盖 `.devsys/` 项目内**领域数据的落盘层**与**M3 工作流/审批/就绪判定三层应用逻辑**：任务（WorkItem）、事件流、Run 记录、决策/发现/工件记录、审批记录、工作流策略文件、就绪判定引擎，以及基于文本扫描的关键字检索。它建立在 [存储基元](存储错误语义.md) 的事务与锁之上，向上提供 Go API，检索另有 CLI 入口；不提供业务状态机（状态机由 `internal/domain` 提供）。

## 模块定位

- **做什么**：把领域记录写成稳定键序的 YAML/JSONL 文本文件；分配全局唯一 ID；提供乐观并发更新与不可变版本链；M3 起在工作项之上承接工作流策略加载与 last-known-good 缓存、门禁与质量门、审批生命周期、就绪判定与 next 优先级推荐。
- **不做什么**：不提供 MCP 工具（M4.2）、不执行 hook（M6）、不做任务派发（M6）。

M2 起在可靠文本存储之上又承接了**调度**与**对账/修复**两块职责：状态机九态图与保守转换（`internal/domain/state.go`）、租约文件 `.devsys/scheduling/<id>.yaml` 下的领取/心跳/释放/重试（`internal/workitem/claim.go`），以及只读检查 / 恢复 / 确认式修复（`internal/storage/inspect.go` + `internal/reconcile/`）。M3 起又承接：

- **工作流策略层** `internal/workflow/`：解析 `.devsys/workflows/<id>.md`（YAML front matter + 提示词正文），校验步骤/转换/门禁/钩子/限额/质量门；评估白名单条件；渲染模板与展开环境变量；last-known-good 缓存（`.devsys/.cache/workflows/`）。
- **审批服务** `internal/approval/`：持久化 `.devsys/approvals/approval-<N>.yaml`，实现 request → decide → consume 生命周期；consume 永远在转换事务的 Guard 内完成，失败即整单回滚。
- **就绪判定** `internal/next/`：纯函数 `Evaluate` 根据待恢复事务、过期/孤儿租约、滞留审查、阻塞、元数据/策略问题、待决审批等风险输出 PASS/CONCERNS/FAIL 判定，并按 §7.4 优先级给出唯一推荐动作。

三者仍全部落在 storage 的事务与锁之上，自身不引入新的锁类型。

## 职责边界

| 子层 | 目录 | 职责 |
|---|---|---|
| WorkItem | `internal/workitem/` | 一任务一文件，`<前缀>-<序号>` ID，CAS 分配；M2 状态机转换、租约领取/释放/重试；M3 转换事务的 Guard 钩子（供审批消费）、记录传播（propagate）、工作流实例操作 |
| 事件流 | `internal/events/` | JSONL 按月分片追加，评论一级回复；M2 提供 `AppendTx` 让调度在同一事务里追加事件；M3 新增 `AppendBatchTx`（按 shard 分组、一次 append）支撑状态事件 + 传播事件 + 失效事件同批提交 |
| Run | `internal/run/` | `run-<YYYYMMDD>-<N>`，携带 §11.3 上下文快照 |
| 记录 | `internal/record/` | decision/finding/artifact 一记录一文件；Artifact 版本链；M3 新增 `ListArtifacts` 给门禁证据收集 |
| 检索 | `internal/search/` | 无索引文本扫描，排除 `local/`、`.cache/` |
| 只读检查 | `internal/storage/inspect.go` | 共享项目锁下的 `Inspect` / `InspectUnlocked`，**不**创建锁文件、**不**触发恢复 |
| 对账/修复 | `internal/reconcile/` | Doctor（只读）/ Recover（释放过期/孤儿租约）/ RepairDryRun + RepairApply（确认式） |
| 工作流策略 | `internal/workflow/` | M3 新增：front matter 解析、严格 located 校验、条件求值白名单、门禁与质量门、last-known-good 缓存、模板渲染与环境变量展开 |
| 审批 | `internal/approval/` | M3 新增：审批记录持久化、请求/决定/消费生命周期、消费在转换事务 Guard 内、离开阶段即作废 |
| 就绪判定 | `internal/next/` | M3 新增：纯函数 `Evaluate`，PASS/CONCERNS/FAIL 与 §7.4 推荐动作；接入待决审批与策略问题作为风险 |

物理布局见 [架构设计](架构设计.md)；错误语义见 [存储错误语义](存储错误语义.md)。
